# Agent update notes

Copy this template into a new file named `YYYY-MM-DD-HHMM-agent-name.md` for a substantial task or handoff. Keep one file per agent session to reduce simultaneous edit conflicts.

```md
# Update: short task name

- **Who / agent / harness:**
- **Started:**
- **Status:** planned | in progress | blocked | complete
- **What changed:**
- **Files or pull request:**
- **Decision or blocker:**
- **Next action / handoff:**
```

Do not record secrets or personal credentials here. Follow `AGENTS.md`: only commit and push when the human has authorized it. Teammates can see an update after it is pushed.
